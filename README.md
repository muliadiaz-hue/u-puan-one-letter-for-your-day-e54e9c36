One Letter for Your Day — a program that writes exactly one letter, **Y** (for *Yawn*, the word for a boring day), to `/output/entry.txt`. Nothing else: no newline, no spaces, just the single byte `Y`.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to choose a different output directory; without it the program writes to `/output`.
